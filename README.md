# LocalCloud

Приветствую! Это мой первый крупный проект (не судите строго :3).  
Его суть: сохранять пользовательские файлы на локальном сервере (ПК, на котором запущен скрипт).

## Как это работает

При запуске скрипта на роутере, к которому подключён ПК, на порту 5000 создаётся локальная HTML-страница (можно назвать сайтом).  
Через неё можно загружать и скачивать файлы в/из папки `files`.

## Технологии

- Python 3
- Flask

## Как запустить

1. Установи Python 3
2. Установи Flask: `pip install flask`
3. Склонируй репозиторий (файл `main.py` и пустую папку `files`)
4. Открой терминал и перейди в папку с файлом (`cd путь`)
5. Запусти: `python main.py`
6. Перейди по IP-адресу, который появится в консоли

## Важно

Это бета-версия облака. Возможны баги, некоторые типы файлов могут не поддерживаться.
